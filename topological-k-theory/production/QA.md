## 正本と再生成

章の順序は chapters/00- から 07-。index.qmd はポータルの入口。PDFはISO B6、本文11.5 ptの二段組。表紙と目次を含め101ページで、目次は一ページ。本文を横長の数式ごとに読み直せるよう手で行を分け、組版上の段幅を超える別行数式にはTypstの幅調整を適用する。

生成はリポジトリのルートで行う。使用版は Python 3.13、Quarto 1.11.9、バンドルされた Typst 0.15.1。日本語書体は Yu Mincho と Yu Gothic。Windowsの非ASCIIのQuarto実行ファイルパスではPandocのLuaローダーが失敗したため、同じツールをASCIIパスへコピーして実行した。既存のインストールはそのまま使える環境ではコピー不要。

python scripts/validate_site.py

算術の再検算では単位円の偏角差、関係行列の行列式と最大公約数、Laurentの範囲の数え上げと次数1までの有理積を使用。$\mathcal O(k)$ は $-12\le k\le12$ で指数を照合した。これは一般定理の証明の検証とは別の検算である。

借用した主な事項は次のとおり。

- コンパクトな有限CW対における商・円錐・ホモトピー拡張、セルと特異コホモロジーの一致、通常のThom同型とEuler類の零点評価、Chern類の存在と射影束定理。第1〜5章で、該当する対や複素向きを明示して使った。積定理とそこからの複素Bott周期性、複素K理論のThom同型は本文で証明した。 [Hatcher, Vector Bundles and K-Theory](https://pi.math.cornell.edu/~hatcher/VBKT/VB.pdf)
- Clifford加群の構成と実周期性は第7章の展望で使った。零切断の外で可逆な束の対は§11、Spin束への適用は§14。 [Atiyah–Bott–Shapiro, Clifford Modules](https://www.math.ens.psl.eu/~benoist/refs/ABS.pdf)
- 閉多様体上で滑らかな楕円作用素がSobolev空間間でFredholmとなること、核・随伴核の正則性、埋め込みによる位相的指数の独立性、解析的指数との一般的一致。$\mathbb CP^1$ の左右の計算には一般的一致を使わず、最後に値を照合した。 [Melrose, From Microlocal to Global Analysis](https://math.mit.edu/~rbm/18-157-S14/iml.pdf) [Melrose, Lecture 28・30、Topic 4・6](https://math.mit.edu/~rbm/Bkly08/Bkly08.html) [Atiyah–Singer III](https://annals.math.princeton.edu/1968/87-3/p07)

## 試読と組版

序章の最初の2本文ページで問い、赤道の計算、三つの到達点を読む。章1・2は貼り合わせと座標の追加を区別し、章3は高次係数の消去と逆写像を同じ多項式で追える構成。章4・5は射影空間の整数格子を先に計算し、Chern指標に見えない差が円周束でどう残るかを示す。章6は余核を有限行列で導入し、球面の可解条件に戻る。「特性類・K群・指数は何を区別するか」は章7で逆引きできる。
