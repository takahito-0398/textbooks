# 『位相的K理論を読む』一段組改訂版の制作・検証記録

改稿の基点は公開コミット `9b90b2f77ace401a2e868604e6a8a2324d51b440`。添付の組版見本に合わせ、本文を一段で読み進め、黒四角から節を見つけ、別行数式の番号を右に追える構造にした。

## 内容と版面

- 序章を含む22章に章の導入とまとめを置いた。主要207節には、節で解く問いと結論を書き下ろした。定義、定理、ポイント、コラム、途中計算を枠とラベルで区別する。
- 途中計算欄は28か所。たとえば第1章では接線方向の微分を半径と角度に分け、第6章では行列の左右どちらから基本変形するかを追う。第12章のファイバー積分では、積を低次数の四項へ整理してから、どの項を積分するかを示した。第20章ではFourier係数の接続から指数を足して、減衰の二次項を得る。
- 別行数式389本、うち番号つき312本。本文中の式・図・表への参照は章内329件、章をまたぐ式参照3件。図26点を27か所に置き、表14点を収録。全体の三つの計算経路、Chern指標の次数ごとの成分、トーラス上の係数の偶数列と奇数列を作図した。
- ISO B5判（176×250 mm）、一段組、本文10.7 pt、左右各25 mm、上23 mm、下24 mm。本文の行間はTypstで0.68 emを加える設定とした。幅に合わせて数式全体を縮める処理を外し、数式と本文に同じ基準サイズを使う。肩付き文字などには数式の従来の組版規則を用いる。
- 表紙と一頁の目次を含め205頁。本文は3〜205頁の203頁。式番号はPDFで全巻通し、Webで各章通し。章をまたぐ参照は同じ式へ向けた。

## 再生成

章のQMDを単一の正本とし、リポジトリルートで以下を実行する。制作環境は Python 3.13.14、Quarto 1.11.9、Typst 0.15.1。本文と見出しの日本語書体は Yu Mincho と Yu Gothic。図を再生成する場合は Pillow 13 を用いる。

```powershell
python topological-k-theory/production/verify_examples.py
python topological-k-theory/production/verify_edition.py
python topological-k-theory/production/draw_figures.py
python scripts/build_topological_k_pdf.py
quarto render
python scripts/validate_site.py
```

Quarto実行ファイルを明示する場合はPDF生成に `--quarto` を、図の書体ファイルを指定するには作図に `--font` を付ける。PDF生成は各章のSHA-256と成果物のSHA-256を出力する。配布PDFのSHA-256は `3821ad68f50abeceeb75809b150492073230e8da2093293f78b6b99f249cb2cc`。再生成後は配布ファイルのハッシュを取り直す。

## 検証

- 正本で全章・全主要節の導入とまとめの数、式・図・表のIDと行先、図版PNGの存在を検査した。巻き数とKoszulの符号、レンズ空間のSmith不変因子、射影空間のTodd積分と対角線、族の指数、トーラスの漸化式は算術を再検算した。
- PDFは全頁の縮小一覧と、章の導入、途中計算、目次、図表を拡大して組版を確認した。途中計算の見出しだけが頁末に残る箇所を修正した。数式の字形の左右端に版面を越える箇所がないこと、TeX変換警告と未解決の参照記号がないこと、目次の22リンクが各章の開始頁を指すことを確認した。日本語と数式のフォントはPopplerで埋め込みを確認した。
- Quartoでポータル全体をレンダリングし、HTMLで332件の式・図・表の参照先を照合した。Edgeでは320、390、1366pxで全章の本文、数式、図、導入・まとめ・途中計算の表示を確認した。
- 印刷、独立試読、Edge以外の実機での表示は未検証。
