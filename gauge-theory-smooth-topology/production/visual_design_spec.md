# Visual Design Spec

作業日: 2026-10-13

## ラベル規約

| 種類 | 表示方針 | 備考 |
|---|---|---|
| definition | 本文内で太字語と直後の説明を使う | 過剰な枠囲みはしない |
| proved-theorem | 本文で証明する主張として説明 | 必要な場合だけ節見出しで明示 |
| quoted-theorem | `引用定理｜...` のラベルを付ける | 赤い警告風表示を使わない |
| proof-outline | `証明の骨格：...` として青系noteで整理 | 研究級入力と本文計算を分ける |
| note-warning | 実際の誤読・混同への注意に限定 | 警告色は乱用しない |
| example | 本文内の小見出しと計算で示す | 図表化は必要な場合のみ |
| exercise | `節内演習` ラベルを保持 | 問題と解答を同じ枠内に置く |

## 今回の適用

- 引用定理系の `callout-important` を廃止し、`callout-note` と `引用定理｜...` ラベルへ統一した。
- 警告系は「非平滑化可能性は異種滑らかな構造の組ではない」「有限次元性の根拠」など、読者の誤読を防ぐ箇所に限定した。
- 図12は情報量を維持しつつ文字サイズと文を短くした現行版を保持した。
- 付録Bでは解答番号前の縦間隔と番号ラベルを維持し、探索性を高めた。
