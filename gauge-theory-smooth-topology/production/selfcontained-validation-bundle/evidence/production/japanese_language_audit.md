# 日本語校閲記録

## 方針

固定語の置換だけでなく、段落単位で数学的意味に沿う日本語へ整える。英語のまま置く語は、固有名詞、定着した略号、初出併記、原著タイトルに限定する。

## 用語統一

- homeomorphic: 同相である
- diffeomorphic: 微分同相である
- Poincare duality: ポアンカレ双対性
- fundamental class: 基本類
- normal bundle: 法束
- Euler number: オイラー数
- adjunction inequality: 随伴不等式
