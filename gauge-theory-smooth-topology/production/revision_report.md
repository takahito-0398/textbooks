## 実施した修整

1. PDF目次・しおりの過密を解消した。
   - 章内小見出しは本文中の太字ラベルとして残し、PDFしおりには出さないようにした。
   - 本文の説明、計算、演習、図表は削除していない。
   - PDFしおりは273件から28件へ削減した。
   - 紙面上の目次は6ページ相当から1ページへ短縮した。

2. 第16章と付録BのWeitzenbock最大値評価を修正した。
   - 欠落していた加算記号を補い、
     `1/4 |Phi|^4 <= s_-/4 |Phi|^2 + C|eta||Phi|^2`
     の形に直した。
   - 最大点で `|Phi|^2=0` の場合と、正の場合に `|Phi|^2` で割る場合を分けて書いた。
   - PDF 85ページと112ページで表示確認した。

3. 基礎演習解答を補強した。
   - 基礎演習2に、円周から北極を除く立体射影と逆写像を明示した。
   - 基礎演習9に、非可換な2つの行列 `B,C` と `BC-CB` の具体計算を追加した。
   - PDF 107-108ページで表示確認した。

4. 演習解答30と31の視覚的な連結を解消した。
   - 30番の補足段落と31番の間に段落分離を入れた。
   - PDF 111-112ページで、31番が独立した項目として読めることを確認した。

5. 第18章の線束とKahler幾何の説明を補正した。
   - `c1(O(d))` はコホモロジー類であることを明記し、`u=PD[pt] in H^2(CP^1;Z)` として型をそろえた。
   - Euler列とWhitney積公式から `c(TCP^2)=(1+H)^3`、`c1(TCP^2)=3H`、`K_CP^2=-3H` へ進む説明を補った。
   - PDF 93-94ページで図と本文の接続を確認した。

6. 第13章のDonaldson対角化ルートを明確化した。
   - 本章の主線は `SU(2)` 束、`c1(E)=0`、`c2(E)[X]=1` であると明示した。
   - `SO(3)` や characteristic vector を使う道筋は、文献上の別ルートとして扱った。

7. 第1章の初学者向け導入を補強した。
   - 円周の2枚チャート、立体射影、逆写像、遷移関数 `u=1/t` を具体式で追加した。
   - `x -> x^3` は同相だが微分同相ではない理由を、逆写像の滑らかさで説明した。
