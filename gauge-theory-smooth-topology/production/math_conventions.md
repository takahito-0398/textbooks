# 数学規約

- 基本対象 `X` は閉・連結・向き付け可能な滑らかな4多様体とする。
- `F_A^+=0` をASD方程式と呼ぶ。
- Yang-Mills汎関数は本文の規約に合わせて `YM(A)=||F_A||_{L^2}^2` とする。
- 向き反転では自己双対部分と反自己双対部分が入れ替わる。
- `Spin^c` の行列式線束接続を `A` とするとき、ゲージ変換の係数2を本文全体で保持する。
- 接続へのゲージ作用は `A^g=g^{-1}Ag+g^{-1}dg` とし、`g=e^φ` の無限小作用は `+d_Aφ` である。Coulomb代表を探す一次方程式は `d_A^*d_Aφ=-d_A^*a` とする。
- `Spin^c` の `A` は `det W^+` の接続である。このため `A -> A+a` のときスピノル接続の可換部分は `a/2` だけ変化し、Dirac線形化は `D_Aφ + 1/2 ρ(a)Φ` を含む。
- `Euler class` はオイラー類、`Euler characteristic` はオイラー標数、`Euler number` はオイラー数として区別する。
- 多様体の基本類 `[X]` とSeiberg-Witten基本類は別概念として扱う。

## 増補で固定した追加注意

- パウリ行列は `{σ_i,σ_j}=2δ_ij I` を満たすが、Riemann計量のClifford作用は `{c(v),c(w)}=-2g(v,w)I` を満たす。本書では `-iσ_j` を用いて符号を合わせる。
- ASD変形複体の複体性はBianchi恒等式ではなく、`d_A^2` とASD条件から導く。
- Kähler面の正スピノル表示は、正準Spin^c構造では `Λ^{0,0}⊕Λ^{0,2}`、線束 `E` でひねると `(Λ^{0,0}⊕Λ^{0,2})⊗E` になる。
- Donaldson対角化定理の説明では、可約リンクの有限次元模型と一般定理の引用範囲を区別する。有限次元模型を定理の証明として扱わない。
