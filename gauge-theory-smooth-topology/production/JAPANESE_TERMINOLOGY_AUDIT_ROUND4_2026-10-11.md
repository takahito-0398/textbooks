# Round 4 Japanese terminology audit

## Policy

Established Japanese mathematical terminology is used in explanatory prose. Roman terms remain where they are formulas, group names, theory names, bibliography data, or useful first-use search terms.

## Replacements applied in visible prose

| Previous / corrupted | Current |
|---|---|
| `cokee` | `coker` only as formula operator; 余核 in prose |
| `Kueanishi` | Kuranishi |
| `て射` | 全射 |
| `ららかな` | 滑らかな |
| `in定値`, `in 定値` | 不定値 |
| `定確` | 正確 |
| `滑らかなである` | 滑らかである |
| `滑らかな化` | 平滑化 |
| `stabilizer` | 安定化群 |
| `obstruction` | 障害 |
| `regular` | 正則 |
| `principal symbol` / `symbol` in prose | 主記号 |
| `estimate` | 評価 |
| `dimension` in prose | 次元 |
| `connection` in prose/table | 接続 |
| `bound` | 上界 / 評価 depending on context |
| `a priori` | 先験的 |

## Deliberate exceptions

- Donaldson, Seiberg--Witten, Taubes, Dirac, Hodge, Uhlenbeck, Kuranishi, Sard--Smale, Weitzenböck remain as standard names.
- `Spin^c`, `SU(2)`, `SO(3)`, `U(1)`, `ker`, `im`, `coker` remain in formulas and notation tables.
- Bibliography entries and machine-readable registry keys are not rewritten as prose.
