# 数学規約

- 基本対象 `X` は閉・連結・向き付け可能な滑らかな4多様体とする。
- `F_A^+=0` をASD方程式と呼ぶ。
- Yang-Mills汎関数は本文の規約に合わせて `YM(A)=||F_A||_{L^2}^2` とする。
- 向き反転では自己双対部分と反自己双対部分が入れ替わる。
- `Spin^c` の行列式線束接続を `A` とするとき、ゲージ変換の係数2を本文全体で保持する。
- `Euler class` はオイラー類、`Euler characteristic` はオイラー標数、`Euler number` はオイラー数として区別する。
- 多様体の基本類 `[X]` とSeiberg-Witten基本類は別概念として扱う。
