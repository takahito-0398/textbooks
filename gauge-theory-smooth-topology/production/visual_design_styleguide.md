# Visual Design Styleguide

作業日: 2026-10-13

## 適用範囲

- `gauge-theory-smooth-topology` のPDF/Quarto出力に限る。
- 今回は大規模なデザイン刷新ではなく、104ページ版の内容を保つための局所改善とする。

## 図

- 図中の本文説明は日本語を正本とする。
- 群名、空間名、標準記号、数式は欧文・数式表記を残す。
- PDF上で縮小される図は、小さい説明文を短くし、文字サイズを優先する。
- 図が示していない対象をキャプションに含めない。

## 本文

- 長い証明・構成では、必要に応じて「本文で追うこと」「引用すること」「結論」を表で分ける。
- 色だけで意味を区別せず、タイトル・ラベル・本文で役割が分かるようにする。
- 混在語は、数学用語として必要な固有語を除いて日本語へ寄せる。

## 付録答案

- 解答番号を検索・視認しやすくする。
- PDF版では解答番号前に微小な縦間隔を入れ、連続した答案が詰まりすぎないようにする。
